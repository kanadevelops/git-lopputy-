# Git, VS Code ja GitHub - lopputyö

# Projektin tarkoitus

Tämän projektin tarkoituksena oli harjoitella Gitin, VS Coden ja GitHubin käyttöä projektityössä.

# Mitä tein

Projektin aikana:

loin Git-repositorion VS Codessa
tein vähintään viisi committia
loin feature-page-haaran
tein muutoksia sekä  feature-page-haaraan
loin merge-konfliktin
ratkaisin merge-konfliktin
yhdistin haaran
julkaisin projektin githubiin
loin hithubissa Pull Requestin
ratkaisin pull rquestin
yhdistin pull rquestin main-haaraan

Käytetyt työkalut

 Visual Studio Code
 GitHub

 Mitä opin

Opin käyttämään Gitin perustoimintoja VS Codessa. Opin myös, että  haarat vovat aiheuttaa konfliktin, jos samaa kohtaa tiedostosta muutetaa.

 index.html – projektin HTML-sivu
