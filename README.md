# Git, VS Code ja GitHub - lopputyö

## Projektin tarkoitus

Tämän projektin tarkoituksena oli harjoitella Gitin, VS Coden ja GitHubin käyttöä projektityössä.

## Mitä tein

Projektin aikana:

* loin Git-repositorion VS Codessa
* tein vähintään viisi committia
* loin `feature-page`-haaran
* tein muutoksia sekä `main`- että `feature-page`-haaraan
* loin merge-konfliktin
* ratkaisin merge-konfliktin
* yhdistin haarat
* julkaisin projektin GitHubiin
* loin GitHubissa Pull Requestin
* ratkaisin Pull Requestin konfliktin
* yhdistin Pull Requestin `main`-haaraan

## Käytetyt työkalut

* Visual Studio Code
* GitHub

## Mitä opin

Opin käyttämään Gitin perustoimintoja VS Codessa. Opin myös, että kaksi eri haaraa voivat aiheuttaa merge-konfliktin, jos samaa kohtaa tiedostosta muutetaan eri tavalla.


## Projektin sisältö

Projektissa on yksinkertainen HTML-sivu ja siihen liittyvä CSS-tyylitiedosto.

Tärkeimmät tiedostot ovat:

* `index.html` – projektin HTML-sivu
* `style.css` – sivun tyylit
* `README.md` – projektin dokumentaatio
